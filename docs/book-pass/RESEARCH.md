# Book Pass Research

The product brief at `/home/pk/Downloads/book-pass-prd.md` is the source of truth. The useful product insight is the forced two-person loop: draw, pass, open, draw back. A static, fragment-encoded note keeps that loop private and removes backend work.

## Build decision

Vite + vanilla TypeScript, `perfect-freehand`, `simplify-js`, and `fflate`. One responsive drawing surface, one received-note surface, native sharing, no account system. The visual reference is Indian school stationery; the Deluxe Saloon lesson is specificity and immediate recognition, not copied styling.
